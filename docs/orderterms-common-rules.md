# Общие правила сроков — Calc 1.16.10

Исправлен доступ к существующему редактору OrderTermsSettings из раздела
«Управление сроками» и настроек календарной функции модуля. Переключатель
«Календари / Общие правила» использует общую защиту несохранённых черновиков.
Выбор календаря внутри редактора витрины остаётся отдельным календарным экраном.

Правила сохраняются существующим API OrderTerms через settingsAppend с CAS
и settingsRead с проверкой hash. Рабочая интеграция сроков выключена; обработчики
заказов и фоновые задания этим выпуском не включаются.

Исходный редактор: CalcConfig f21a5c9b95815b8c60565808f7d82d7ebe2545a8. Собран из committed
архива; несвязанные рабочие изменения FormFirstAuthoringEditor не включены.
Локально: 12 проверок OrderTerms UI/модели, 300 документных проверок, PHP
settings/list 33 и storage 22, TypeScript/Vite build. Четыре старых ошибки общей
CC UI-contract suite воспроизведены на исходном 4e22832 и не относятся к патчу.
Нативные authoring/save/reload и lifecycle требуют отдельной приёмки выпуска.
