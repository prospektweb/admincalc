# Листовой калькулятор: офсет

Пакет создаёт обычные формулы LOGIC_JSON v2 и явные INPUTS/OUTPUTS.
Код исполнения CalcConfig и Calc Server не заменяется отдельным калькулятором.

Уточнение владельца 07.09.2026: готовая пластина — 178,57 руб;
приладка — 2012 руб за комплект форм; 150 листов на комплект.
Прежняя трактовка ставки «за цвет» была ошибочной и заменена.
Закупленные готовые пластины учитываются материалом, без собственного CTP.

## Владение данными

- Оборудование: секции, переворот, направление своего оборота, ограничения
  толщины, запас на комплект и коэффициент сложного материала.
- Вариант операции: ставки одного прогона по числу активных секций,
  пять составляющих норматива приладки комплекта, процент за каждый цвет
  и повторная приводка без смены форм.
- Материал: цена, размеры, масса и толщина.
- Глобальные настройки: технологический запас и выход после обработки.
- Глобальные результаты: выбранный спуск, листы, прогоны, формы и геометрия.

## Методика

Сравниваются технически допустимые варианты с отдельными комплектами форм
и со своим оборотом. Для каждого отдельно округляется потребность в исходных
листах, учитываются потери каждого прогона, приладочная бумага, стоимость
всех пластин, приладок и прогонов. Порог тиража не задаётся.
Разная красочность сторон может сделать свой оборот дороже по прогонам даже
при одинаковом выходе изделий. Общая палитра сторон задаётся явно.

Физический лист, листопрогон, красочный оттиск, комплект форм и пластина —
разные величины. Брак приладки не поступает в ламинацию и упаковку.

только явно выбранный рабочий граф; исходные данные сохраняются для отката.

## Послепечатная обработка

Рулонная ламинация расходует только листы для дальнейшей обработки.
Выбирается допустимая ориентация подачи с минимальным расходом плёнки.
Цена рулона умножается на использованную долю длины; двусторонняя ставка
работы уже учитывает обе стороны и повторно не удваивается. Зазор 4 мм и
запас плёнки 3% перенесены в оборудование Bulros (1084). Масса и толщина
слоёв плёнки переходят в резку и упаковку.

Резка учитывает стопы по допустимой высоте выбранного резака, сетку спуска,
вылеты и подготовительный раскрой исходных листов. Существующая шкала
трудоёмкости 5–20% сохранена; это коммерческая норма сайта, не замер времени
реза. Для перехода к оплате по времени нужны фактическая ставка и замер.

Упаковка проверяет размещение стоп, массу вложения, полезную высоту короба
и лимит изделий. А3 получает большой короб. Масса коробов 197/378 г
восстановлена из исходных карточек 5618/5619 вместо ошибочных 9,85/18,9 г.
Масса заказа равна массе изделий и всех коробов; повторного деления массы
изделия на тираж нет. Сохраняется выбранная заказчиком ранее ставка 120 руб
за короб (операция 5761). Её карточка имеет более узкое название — до 100 см²,
от 5000 экземпляров. Применимость этой ставки ко всем форматам требует
уточнения владельца; новые цены для больших форматов не выдумывались.

## Выполнение и проверка

`build-recipe.mjs` принимает JSON ответа INIT выбранной рабочей версии и
каталог с необходимыми сущностями, затем создаёт recipe.json и семь файлов
стандартного импорта. Конкретные ID намеренно ограничивают этот рецепт
версией 12 пресета 12740, рабочий граф 16411.

`admin.php` — только CLI под настроенным аккаунтом хостинга. Размещать
исполняемую копию вне document root. Режим `preview` проверяет каждое старое
значение и версию реестра; `apply <sha256>` использует точный хеш просмотренного
recipe.json. Изменение проходит координаторы глобальных данных, версии и
владения графом, сохраняет полный backup и проверяет каждую запись чтением.
Общие настройки клонируются штатным сервисом; исходные настройки остаются.
Смена формата выполняется отдельным режимом `form-fix <contentHash>`:
он снимает ровно два прежних ограничения OFSET=90×50 и сохраняет остальные
поля, связи и ограничения в общей транзакции формы и полного снимка.

Проверка на действующих движках (пути репозиториев можно передать junction):

```powershell
node tools/recipes/sheet-offset/verify.mjs <init.json> <calcconfig> <calc-server> <report.json>
```

Для проверки уже сохранённого INIT добавить `--live`: повторное построение
и наложение рецепта не производится. Требуется собранный `calc-server/dist`.
Проверяется 31 сценарий, включая восемь красочностей, два независимых макета,
150/300 г/м², исправленную привязку 80 г/м², ламинацию с одной/двух сторон,
А3, размеры коробов и экономический выбор оборота. Неподдерживаемый формат,
неоценённая третья краска и отсутствующая глянцевая бумага 120 г/м² должны
дать неполный диагностический расчёт и отказ строгого серверного расчёта.

Пример: 1000 изделий 90×50, 4+4, матовая 150 г/м² — свой оборот,
4 пластины, 1 комплект, 150 приладочных листов, 269 тиражных листопрогонов,
286 печатных листов с отходами, 72 исходных листа. Для 1000 А3 4+4 —
чужой оборот, 8 пластин, 2 комплекта, 300 приладочных листов.

Коэффициент поверхности материала по умолчанию равен 1. Нельзя приписывать
бумаге числовое удорожание только по названию «дизайнерская» или по плотности.
Измеренная толщина и подтверждённые нормы цеха хранятся отдельно.

## Составляющие приладки

Вариант операции 1074 «Приладка одного комплекта форм Ryobi 524HXX»
содержит следующие параметры. Они относятся к нормативу этой операции.

| Параметр | Значение | Единица |
| --- | ---: | --- |
| MAKEREADY_SHIFT_LABOR_RUB | 5670 | руб/смена |
| MAKEREADY_SHIFT_RENT_RUB | 4050 | руб/смена |
| MAKEREADY_SHIFT_CONSUMABLES_RUB | 1620 | руб/смена |
| MAKEREADY_PLANNED_SETS_PER_SHIFT | 7,5 | комплектов/смена |
| MAKEREADY_REPAIR_RESERVE_PER_SET_RUB | 500 | руб/комплект |

Норматив комплекта: (5670 + 4050 + 1620) / 7,5 + 500 = 2012 руб.
Каталожная закупочная цена операции сохранена для совместимости, но эта
схема её больше не читает. Единственный источник расчёта — пять параметров.

Шкала процентов выбирается по числу комплектов: до 2 — 15%, 3–5 — 12%,
6–10 — 9%, от 11 — 5%. Это процент за каждый цвет. Для одинаковых комплектов
базовая стоимость = себестоимость × (1 + цветов в комплекте × процент / 100).
Для разных комплектов используется среднее число цветов, взвешенное
одинаковым нормативом комплекта. 4+0: 2012 → 3219,20 руб; А3 4+4:
два комплекта, 4024 → 6438,40 руб. Нормы толщины и повторной приводки
применяются к себестоимости до наценки.

Отчёт показывает комплектность, три статьи смены, резерв, норматив,
коэффициент работы, себестоимость и сумму наценки. Дополнительные выходы
раскладывают себестоимость заказа на ФОТ, аренду, расходники и ремонт.

`revise-makeready.mjs` создаёт ограниченное обновление ранее установленного
рецепта: свежий рабочий снимок с globalAuthority → рецепт и INIT для проверки.
Четвёртый аргумент — текущая публикация, предоставляющая полный контекст формы.
Миграция не повторяется поверх уже изменённых формул: старые значения
проверяются до записи. `admin.php` применяет её с backup/CAS и клонированием
двух настроек. В регрессию входят изменение ФОТ, независимость от каталожной
закупочной цены и отказ при нулевом плановом числе комплектов.

## Доступность материалов на форме

`align-form.php <contentHash>` согласует три поля формы с выбранным деревом
материалов: печатный материал, тип бумаги и плотность. Только для OFSET
доступны настроенные типы и сочетания плотностей. Правила других методов
сохраняются, включая их прежние ограничения. Цены отсутствующих материалов
не подставляются от другой бумаги.

Скрипт размещается вне document root вместе с `form-availability.php`.
Он проверяет точный contentHash, создаёт backup полного снимка и формы,
компилирует кандидат и сохраняет через штатные координаторы версии.
После проверки рабочего редактора версия публикуется обычным действием ЦУ.
Проверка 276 комбинаций условий:

```powershell
php tools/recipes/sheet-offset/verify-form.php <publication.json> <frontcalc-path>
```
